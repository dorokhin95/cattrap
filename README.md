# 🐱 CatTrap — 2D Trap Platformer

> **«Ничему не верь»** — динамичный 2D платформер про хитрого и стойкого котика, где каждый шаг готовит неожиданную ловушку. Смерть здесь — не наказание, а ключ к пониманию правил уровня!

📁 **Репозиторий:** [https://github.com/dorokhin95/cattrap](https://github.com/dorokhin95/cattrap)

## 🎮 Ключевые особенности

* **Честная физика:** Детерминированные триггеры на игровых часах Phaser, фиксированный шаг Arcade Physics (fixed timestep 60 FPS), отсутствие зависимости физики от частоты кадров.
* **Идеальный отклик управления:**
  * Коллайдер котика 14×19 px (спрайт 24×24 px).
  * Смертельный хитбокс опасных объектов составляет 65–75% от их графики.
  * Coyote Time (100 мс) и Jump Buffering (120 мс).
  * Переменная высота прыжка (Variable Jump).
  * Мгновенный рестарт после гибели (<400 мс) без утечек и пересоздания графа коллизий.
* **10 готовых уровней Главы 1:**
  * Уровень 1: «Первый подвох» (обучение, статический шип, Pop Spike).
  * Уровень 2: «Не стой» (осыпающийся мост Crumble Block).
  * Уровень 3: «Подожди, куда?» (убегающий портал).
  * Уровень 4: «Беги, кот» (цепная волна шипов за спиной).
  * Уровень 5: «Смотри вверх» (падающий блок 2×2, становящийся ступенькой).
  * Уровень 6: «Пол врёт» (падающий обманный пол).
  * Уровень 7: «Маленький кот» (уменьшение размера до 68% и узкий туннель).
  * Уровень 8: «Лапами вверх» (инверсия гравитации и потолочный забег).
  * Уровень 9: «Почти дошёл» (комбинация осыпающегося пола и убегающего портала).
  * Уровень 10: «Девять жизней» (большой экзамен со всеми ловушками, чекпоинт-коробка и триумф Главы 1).
* **Кроссплатформенность:**
  * Web / GitHub Pages (100% статический билд).
  * Telegram Mini App (полная поддержка Safe Area, BackButton, настраиваемого виброотклика Haptics, расширения viewport).
  * Desktop и мобильные браузеры (полноэкранный двухзонный мультитач контроллер с защитой от залипания пальцев).
  * Адаптивность: бесшовный адаптивный ресайз при смене ориентации экрана (Portrait / Landscape) без блокирующих окон.
* **Процедурный WebAudio синтез:**
  * Моментальная загрузка игры (<100 КБ кода без внешних тяжелых аудиофайлов).
  * Автоплей разблокируется при первом взаимодействии с экраном.
  * Аутентичные ретро-звуки и мягкий chiptune-loop.

## 🛠 Технологический стек

* **Язык:** TypeScript
* **Сборка:** Vite
* **Игровой движок:** Phaser 3 (Arcade Physics с фиксированным шагом)
* **Звук:** WebAudio API (процедурный синтезатор)
* **Тестирование:** Vitest

## 🎯 Управление

### На ПК:
* `A` / `←` — бег влево
* `D` / `→` — бег вправо
* `Space` / `W` / `↑` — прыжок (удерживайте для максимальной высоты)
* `R` — мгновенный рестарт уровня
* `Esc` — пауза

### На смартфонах:
* Полупрозрачные экранные кнопки в нижней части экрана (`←` `→` слева, `JUMP` справа).
* Кнопка паузы `⏸` в правом верхнем углу.
